Sysmon Tray 설치 설명서

작업 표시줄 트레이에 CPU·RAM 사용률을 숫자로 보여 주는 가벼운 모니터링 프로그램입니다.

어떻게 보이나요?

37 CPU 사용률 (초록)
52 RAM 사용률 (파랑)
65 50% 이상 (주황)
92 80% 이상 (빨강)

아이콘의 숫자는 사용률(%)이며 1초마다 갱신됩니다. 마우스를 올리면 자세한 값이 툴팁으로 나옵니다. RAM은 사용량/전체 용량(GB)도 함께 표시됩니다.

설치 전 확인

  • Windows 11 권장 (Windows 10에서도 동작하지만 트레이 고정은 수동으로 해야 합니다)
  • 관리자 권한 불필요 — 현재 사용자 계정에만 설치됩니다
  • 필요 디스크 용량: 약 0.5MB, 별도 런타임 설치 불필요
  • 설치 파일: SysmonTray-Setup.exe 하나

설치 방법

  1. SysmonTray-Setup.exe를 더블클릭합니다.
  2. 설치 마법사에서 다음 → 설치를 누릅니다. (설치 위치는 기본값 그대로 두면 됩니다.)
  3. 마지막 화면에서 “Sysmon Tray 실행”을 체크하고 마침을 누릅니다.
  4. 시계 옆에 CPU(초록), RAM(파랑) 숫자 아이콘이 나타나는지 확인합니다.
설치되는 내용
  • 설치 위치: %LOCALAPPDATA%\Programs\SysmonTray
  • Windows 로그인 시 자동 실행
  • 시작 메뉴에 “Sysmon Tray” 바로가기 추가
  • 설정 → 앱 목록에 “Sysmon Tray” 등록 (제거용)
  • 이전 버전(zip + install.bat)이 설치되어 있으면 같은 위치에 덮어써서 업그레이드됩니다.

트레이에 아이콘이 안 보일 때

프로그램은 실행 시 아이콘을 작업 표시줄에 항상 보이도록 자동 설정합니다. 그래도 ^ 안에 숨어 있다면 아래 중 하나를 따라 하세요.

  1. 작업 표시줄의 ^(숨겨진 아이콘)을 눌러 아이콘을 찾아 작업 표시줄 쪽으로 드래그합니다.
  2. 또는 설정 → 개인 설정 → 작업 표시줄 → 기타 시스템 트레이 아이콘에서 “Sysmon Tray”(두 항목)를 켭니다.

사용 방법

동작결과
아이콘에 마우스 올리기CPU % 또는 RAM % 및 사용량(GB) 툴팁 표시
아이콘 우클릭 → 종료CPU, RAM 아이콘이 모두 종료됨
시작 메뉴 → Sysmon Tray종료한 뒤 다시 실행

제거 방법

  1. 설정 → 앱 → 설치된 앱에서 “Sysmon Tray”를 찾아 제거를 누릅니다.
  2. 프로그램 종료, 자동 실행 해제, 바로가기 삭제, 설치 폴더 삭제가 한 번에 진행됩니다.
  3. 설치 폴더(%LOCALAPPDATA%\Programs\SysmonTray)의 unins000.exe를 직접 실행해도 같습니다.

문제 해결

증상해결
“Windows의 PC 보호” (SmartScreen) 경고가 뜸 이 프로그램은 코드 서명이 없어서 나타납니다. 추가 정보 → 실행을 누르세요. 출처가 확실한 경우에만 진행하세요.
백신이 차단하거나 삭제함 설치 폴더(%LOCALAPPDATA%\Programs\SysmonTray)를 예외로 등록하거나 보안 담당자에게 문의하세요.
설치 파일이 실행되지 않거나 다운로드 직후 사라짐 브라우저나 백신이 차단한 것일 수 있습니다. 다운로드 폴더의 차단 해제 후 다시 실행하거나, 회사 PC라면 보안 담당자에게 문의하세요.
아이콘이 하나만 보임 다른 아이콘이 ^ 안에 있을 수 있습니다. 위 “트레이에 아이콘이 안 보일 때”를 참고하세요.
재설치/업데이트하고 싶음 새 버전의 SysmonTray-Setup.exe를 다시 실행하면 기존 프로그램을 종료하고 덮어씁니다.
